## Instalação

```bash
pnpm add @blips/ai
```

A rolagem usa o `use-stick-to-bottom`, que já vem como dependência. O pacote `ai` é opcional: só entra como tipo (`UIMessage`) no `ConversationDownload` e no `messagesToMarkdown`.

```css
@import "@blips/ui/globals.css";
@import "@blips/ai/styles.css";
```

## Uso

```tsx
import {
  Conversation,
  ConversationContent,
  ConversationScrollButton,
} from "@blips/ai/components/conversation"
import {
  Message,
  MessageContent,
  MessageResponse,
  messageAlign,
} from "@blips/ai/components/message"
```

```tsx
<div className="flex h-[600px] flex-col">
  <Conversation>
    <ConversationContent>
      {messages.map((message) => (
        <Message key={message.id} align={messageAlign(message.role)}>
          <MessageContent>{/* … */}</MessageContent>
        </Message>
      ))}
    </ConversationContent>
    <ConversationScrollButton aria-label="Ir para o fim" />
  </Conversation>
</div>
```

O `Conversation` tem `flex-1` e esconde o overflow; dê a ele um pai com altura definida (`h-*` ou um layout flex que ocupe a tela). Enquanto a pessoa está no fim, novas mensagens e o texto em streaming mantêm a rolagem presa lá. Se ela rolar para cima, o `ConversationScrollButton` aparece.

Para as mensagens, use o [Message](/docs/ai/message). Se você não precisa das partes de IA, o [Message Scroller](/docs/components/message-scroller) da `@blips/ui` cumpre o mesmo papel.

## Exemplos

### Estado vazio

O `ConversationEmptyState` ocupa o espaço da conversa antes da primeira mensagem. Os textos padrão estão em inglês, como no AI Elements: passe sempre `title` e `description` em pt-BR. Com `children`, você substitui o conteúdo inteiro.

<ComponentPreview name="ai-conversation-empty" />

```tsx
<ConversationEmptyState
  icon={<ChatCircleDotsIcon className="size-8" />}
  title="Nenhuma mensagem ainda"
  description="Pergunte sobre contratos, garantia ou financeiro."
/>
```

### Download

O `ConversationDownload` (canto superior direito da demo do topo) gera um `.md` com o texto das mensagens. Ele recebe `UIMessage[]`, o formato do AI SDK, e lê só as partes `text`. Se as suas mensagens vêm de outro backend, monte objetos `{ id, role, parts: [{ type: "text", text }] }`.

```tsx
<ConversationDownload
  aria-label="Baixar conversa"
  filename="conversa.md"
  messages={messages}
  formatMessage={(m) => `**${m.role === "user" ? "Cliente" : "Assistente"}:** …`}
/>
```

## Referência da API

### Conversation

Aceita as props do `StickToBottom` do [use-stick-to-bottom](https://github.com/stackblitz-labs/use-stick-to-bottom). Já vem com `initial="smooth"`, `resize="smooth"` e `role="log"`.

### ConversationContent

Aceita as props do `StickToBottom.Content`. Coluna com `gap-8` e `p-4`.

### ConversationEmptyState

| Prop          | Tipo        | Padrão                                        |
| ------------- | ----------- | --------------------------------------------- |
| `title`       | `string`    | `"No messages yet"`                           |
| `description` | `string`    | `"Start a conversation to see messages here"` |
| `icon`        | `ReactNode` |                                               |
| `children`    | `ReactNode` |                                               |

Aceita as props de `div`.

### ConversationScrollButton

Aceita as props do [Button](/docs/components/button) (`variant="outline"`, `size="icon"`). Só renderiza fora do fim da conversa e precisa estar dentro do `Conversation`. Passe um `aria-label`.

### ConversationDownload

Aceita as props do `Button`, menos `onClick`.

| Prop            | Tipo                                             | Padrão                         |
| --------------- | ------------------------------------------------ | ------------------------------ |
| `messages`      | `UIMessage[]`                                    |                                |
| `filename`      | `string`                                         | `"conversation.md"`            |
| `formatMessage` | `(message: UIMessage, index: number) => string`  | `**Role:** texto`              |
| `children`      | `ReactNode`                                      | `DownloadSimpleIcon`           |

### messagesToMarkdown

```ts
messagesToMarkdown(messages: UIMessage[], formatMessage?): string
```

A mesma conversão do `ConversationDownload`, para quando você quer copiar ou enviar o markdown em vez de baixar.
