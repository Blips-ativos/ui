## Instalação

```bash
pnpm add @blips/ai
```

O `sources` não exige peer opcional. Importe o CSS depois do tema da `@blips/ui`:

```css
@import "@blips/ui/globals.css";
@import "@blips/ai/styles.css";
```

## Uso

```tsx
import {
  Source,
  Sources,
  SourcesContent,
  SourcesTrigger,
} from "@blips/ai/components/sources"
```

```tsx
<Sources>
  <SourcesTrigger count={sources.length}>
    <span className="font-medium">{sources.length} fontes consultadas</span>
    <CaretDownIcon className="size-4" />
  </SourcesTrigger>
  <SourcesContent>
    {sources.map((source) => (
      <Source href={source.url} key={source.url} title={source.title} />
    ))}
  </SourcesContent>
</Sources>
```

O texto padrão do `SourcesTrigger` (sem `children`) é `Used {count} sources`, em inglês, como no upstream.
Em telas pt-BR, passe o rótulo como `children`.

`Sources` é um `Collapsible` da `@blips/ui` (Base UI): aceita `open`, `defaultOpen` e `onOpenChange`.
Cada `Source` é um `<a>` que abre em nova aba (`target="_blank"`, `rel="noreferrer"`).

### Com o AI SDK

No AI SDK, as fontes chegam como parts `source-url` em `message.parts`. Filtre e passe para o componente:

```tsx
const sources = message.parts.filter((part) => part.type === "source-url")

{sources.length > 0 && (
  <Sources>
    <SourcesTrigger count={sources.length} />
    <SourcesContent>
      {sources.map((part) => (
        <Source href={part.url} key={part.sourceId} title={part.title ?? part.url} />
      ))}
    </SourcesContent>
  </Sources>
)}
```

## Referência da API

### Sources

Props do `Collapsible` da `@blips/ui` (Base UI `Collapsible.Root`) mais as da `<div>`.

| Prop           | Tipo                                     | Padrão  |
| -------------- | ---------------------------------------- | ------- |
| `open`         | `boolean`                                | —       |
| `defaultOpen`  | `boolean`                                | `false` |
| `onOpenChange` | `(open: boolean, eventDetails) => void`  | —       |
| `disabled`     | `boolean`                                | `false` |

### SourcesTrigger

Props do `CollapsibleTrigger` (um `<button>`) mais:

| Prop       | Tipo        | Padrão                                     |
| ---------- | ----------- | ------------------------------------------ |
| `count`    | `number`    | obrigatório                                |
| `children` | `ReactNode` | `Used {count} sources` + `CaretDownIcon`   |

### SourcesContent

Props do `CollapsibleContent` (Base UI `Collapsible.Panel`), como `keepMounted` e `hiddenUntilFound`.

### Source

Props do `<a>`. `title` vira o rótulo padrão (com `BookIcon`) quando não há `children`.

| Prop       | Tipo        | Padrão                     |
| ---------- | ----------- | -------------------------- |
| `href`     | `string`    | —                          |
| `title`    | `string`    | —                          |
| `children` | `ReactNode` | `BookIcon` + `title`       |
