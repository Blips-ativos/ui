## Instalação

```bash
pnpm add @blips/ai
```

Este componente não exige nenhum peer opcional. A `@blips/ai` exige `@blips/ui` ^3 e React 19.

Importe o CSS depois do da `@blips/ui`:

```css
@import "@blips/ui/globals.css";
@import "@blips/ai/styles.css";
```

## Uso

```tsx
import {
  WebPreview,
  WebPreviewBody,
  WebPreviewConsole,
  WebPreviewNavigation,
  WebPreviewNavigationButton,
  WebPreviewUrl,
} from "@blips/ai/components/web-preview"
```

```tsx
<WebPreview defaultUrl={urlDaPrevia}>
  <WebPreviewNavigation>
    <WebPreviewNavigationButton tooltip="Recarregar" onClick={recarregar}>
      <ArrowClockwiseIcon className="size-4" />
    </WebPreviewNavigationButton>
    <WebPreviewUrl />
  </WebPreviewNavigation>
  <WebPreviewBody />
  <WebPreviewConsole logs={logs} />
</WebPreview>
```

Use o `WebPreview` quando o agente gera uma página ou app e o usuário precisa vê-lo funcionando. O `WebPreviewBody` é um `<iframe>` com `sandbox` (`allow-scripts allow-same-origin allow-forms allow-popups allow-presentation`) que carrega a URL atual.

A URL fica no `WebPreview`: o `WebPreviewUrl` a edita e confirma no Enter, o `onUrlChange` avisa o app e o `WebPreviewBody` recarrega. Os botões de navegação não têm comportamento próprio: o app decide o que voltar, avançar e recarregar fazem (o `iframe` de outra origem não expõe o histórico).

O `WebPreview` ocupa todo o espaço do pai (`size-full`): dê altura ao contêiner. Para HTML gerado em memória, passe `srcDoc` ao `WebPreviewBody`, que repassa as props ao `iframe` — o exemplo do topo faz assim e não carrega nada da rede.

## Referência da API

### WebPreview

Raiz e provedor da URL e do estado do console. Aceita as props de `div`.

| Prop          | Tipo                    | Padrão |
| ------------- | ----------------------- | ------ |
| `defaultUrl`  | `string`                | `""`   |
| `onUrlChange` | `(url: string) => void` |        |

### WebPreviewNavigation

Barra superior. Aceita as props de `div`.

### WebPreviewNavigationButton

Botão de ícone com [Tooltip](/docs/components/tooltip). O texto do `tooltip` também vira o `aria-label` (passe `aria-label` para trocar). Aceita as props do [Button](/docs/components/button).

| Prop      | Tipo     | Padrão |
| --------- | -------- | ------ |
| `tooltip` | `string` |        |

### WebPreviewUrl

Campo da URL. Confirma no Enter. Aceita as props do [Input](/docs/components/input); `value` e `onChange` tornam o campo controlado pelo app.

| Prop          | Tipo     | Padrão             |
| ------------- | -------- | ------------------ |
| `placeholder` | `string` | `"Digite a URL..."` |
| `aria-label`  | `string` | `"URL"`            |

### WebPreviewBody

`iframe` da prévia. Aceita as props de `iframe`; `src` tem precedência sobre a URL do contexto.

| Prop      | Tipo        | Padrão     |
| --------- | ----------- | ---------- |
| `loading` | `ReactNode` |            |
| `title`   | `string`    | `"Prévia"` |

`loading` é renderizado depois do `iframe`, para um indicador de carregamento que o app mostra e esconde.

### WebPreviewConsole

Console recolhível no rodapé. `children` entra depois dos logs. Aceita as props de `div`.

| Prop           | Tipo                                                                  | Padrão                       |
| -------------- | --------------------------------------------------------------------- | ---------------------------- |
| `logs`         | `{ level: "log" \| "warn" \| "error"; message: string; timestamp: Date }[]` | `[]`                         |
| `label`        | `ReactNode`                                                           | `"Console"`                  |
| `emptyMessage` | `ReactNode`                                                           | `"Nenhuma saída no console"` |

O horário de cada log sai em `pt-BR` (`14:32:05`).
