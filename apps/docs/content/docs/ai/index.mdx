O `@blips/ai` reúne os componentes para construir interfaces de agente sobre a `@blips/ui` v3: conversa,
resposta em markdown com streaming, raciocínio, chamadas de ferramenta, citações, campo de prompt e efeitos
visuais. Ele **compõe** as primitivas da `@blips/ui` (o `Message` e o `Bubble` são os da `@blips/ui`) e não
traz uma segunda família de mensagem.

## Instalação

```bash
pnpm add @blips/ai
```

Exige `@blips/ui` ^3 e React 19. Importe o CSS depois do tema da `@blips/ui`:

```css
@import "@blips/ui/globals.css";
@import "@blips/ai/styles.css";
```

No Next.js, adicione os dois pacotes em `transpilePackages`:

```ts
const config = { transpilePackages: ["@blips/ui", "@blips/ai"] };
```

Não existe barrel: importe cada componente pelo subpath (`@blips/ai/components/<nome>`,
`@blips/ai/fx/<nome>`). Alguns componentes exigem peers opcionais — cada página diz quais.

| Peer opcional | Exigido por |
|---|---|
| `streamdown`, `@streamdown/code`, `@streamdown/math`, `@streamdown/mermaid`, `@streamdown/cjk` | `message` (resposta em markdown) |
| `shiki` | `code-block`, `tool` |
| `@xyflow/react` (+ `@xyflow/react/dist/style.css` no CSS do app) | `canvas`, `node`, `edge`, `connection`, `controls`, `panel`, `toolbar` |
| `media-chrome` | `audio-player` |
| `@rive-app/react-webgl2` | `persona` |
| `react-jsx-parser` | `jsx-preview` |
| `ansi-to-react` | `terminal`, `stack-trace` |
| `ai` | só tipos (`UIMessage`, `ToolUIPart`…), nenhum código de runtime. Como o pacote publica o fonte `.tsx`, em projetos TypeScript instale como devDependency: `pnpm add -D ai` |

### Estilos do Streamdown

Quem usa o `MessageResponse` (componente `message`) ou o `ReasoningContent` (componente `reasoning`) precisa que o Tailwind do app varra o Streamdown e importe o CSS dele. Ajuste os caminhos `../` conforme a posição do seu CSS em relação ao `node_modules`:

```css
@import "streamdown/styles.css";
@import "katex/dist/katex.min.css";
@source "../node_modules/streamdown/dist/*.js";
@source "../node_modules/@streamdown/code/dist/*.js";
/* repita para @streamdown/math, @streamdown/mermaid e @streamdown/cjk se estiverem instalados */
```

O plugin de matemática (`@streamdown/math`) é sempre carregado e usa o KaTeX, que não injeta o próprio CSS: instale `katex` (`pnpm add katex`) e importe `katex/dist/katex.min.css`, senão as fórmulas saem sem estilo.

## Componentes apresentacionais

Os componentes recebem `status`, `state` e `parts` por props. A tradução de eventos — do AI SDK (`useChat`)
ou de um backend próprio, como o AgentOS do Agno — fica no seu app.
