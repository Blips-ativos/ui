# Blips UI

O Blips UI é uma biblioteca moderna de componentes React construída com os primitives do [Radix UI](https://www.radix-ui.com/) e [Tailwind CSS](https://tailwindcss.com/).

## Recursos

- **Acessível** - Construído sobre os primitives do Radix UI para suporte completo de acessibilidade
- **Customizável** - Use variáveis CSS e Tailwind CSS para temas com facilidade
- **Moderno** - Suporta React 17, 18 e 19
- **TypeScript** - Suporte completo a TypeScript com tipos exportados
- **Copiar e Colar** - Use a CLI ou copie os componentes diretamente para o seu projeto

## Instalação

```bash
# Using npm
npm install @blips/ui

# Using pnpm
pnpm add @blips/ui

# Using yarn
yarn add @blips/ui
```

## Início Rápido

Importe e use os componentes na sua aplicação React:

```tsx
import { Button } from "@blips/ui";

export function MyComponent() {
  return <Button>Clique aqui</Button>;
}
```
