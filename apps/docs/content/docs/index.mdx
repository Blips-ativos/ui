# Blips UI

Blips UI is a modern React component library built with [Radix UI](https://www.radix-ui.com/) primitives and [Tailwind CSS](https://tailwindcss.com/).

## Features

- **Accessible** - Built on Radix UI primitives for full accessibility support
- **Customizable** - Use CSS variables and Tailwind CSS for easy theming
- **Modern** - Supports React 17, 18, and 19
- **TypeScript** - Full TypeScript support with exported types
- **Copy & Paste** - Use the CLI or copy components directly into your project

## Installation

```bash
# Using npm
npm install @blips/ui

# Using pnpm
pnpm add @blips/ui

# Using yarn
yarn add @blips/ui
```

## Quick Start

Import and use components in your React application:

```tsx
import { Button } from "@blips/ui";

export function MyComponent() {
  return <Button>Click me</Button>;
}
```
