## Sobre

O Sonner é criado e mantido por [emilkowalski](https://twitter.com/emilkowalski). Para um toast montado sobre o Base UI, sem dependência extra, veja o [Toast](/docs/components/toast).

## Instalação

```bash
npm install @blips/ui
```

Adicione o `Toaster` uma vez, na raiz do app:

```tsx title="app/layout.tsx"
import { Toaster } from "@blips/ui/components/sonner"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="pt-BR">
      <body>
        <main>{children}</main>
        <Toaster />
      </body>
    </html>
  )
}
```

## Uso

```tsx
import { toast } from "sonner"
```

```tsx
toast("O evento foi criado.")
```

## Migrando da v2

A API não mudou. Só os ícones seguem o mapeamento do Phosphor da v3: `error` passou de `WarningOctagon` para `XCircle` e `loading` de `CircleNotch` para `Spinner`.

## Referência da API

Consulte a [Referência da API do Sonner](https://sonner.emilkowal.ski/getting-started) para mais informações.
