## Sobre

O Sonner é criado e mantido por [emilkowalski](https://twitter.com/emilkowalski).

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { toast } from "sonner"
```

```tsx
toast("O evento foi criado.")
```
