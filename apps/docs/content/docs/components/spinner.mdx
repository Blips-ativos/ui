## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Spinner } from "@blips/ui/components/spinner"
```

```tsx
<Spinner />
```

## Customização

O spinner é um ícone do Phosphor (`SpinnerIcon`) com `animate-spin`, `role="status"` e `aria-label`. Para usar outro glifo, renderize o ícone desejado com as mesmas props:

```tsx
import { CircleNotchIcon } from "@phosphor-icons/react"

<CircleNotchIcon
  role="status"
  aria-label="Carregando"
  className="size-4 animate-spin"
/>
```

## Referência da API

### Spinner

Aceita todas as props de um `<svg>`. Expõe `data-slot="spinner"`.

| Prop         | Tipo     | Padrão      |
| ------------ | -------- | ----------- |
| `className`  | `string` | -           |
| `aria-label` | `string` | `"Loading"` |

## Migrando da v2

- **Ícone**: trocou de `CircleNotch` (arco) para `SpinnerIcon` (raios) do Phosphor. É só mudança visual; a API é a mesma.
- **`data-slot="spinner"`** passou a existir no elemento.

Se preferir o arco antigo, use o ícone direto:

```tsx
// v2 (visual)
<Spinner />

// v3 com o arco da v2
<CircleNotchIcon role="status" aria-label="Carregando" className="size-4 animate-spin" />
```
