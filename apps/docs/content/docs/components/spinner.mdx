## Instalacao

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Spinner } from "@blips/ui/components/spinner"
```

```tsx
<Spinner />
```

## Customizacao

Voce pode substituir o icone padrao do spinner por qualquer outro icone editando o componente `Spinner`.

```tsx title="components/ui/spinner.tsx"
import { LoaderIcon } from "lucide-react"

import { cn } from "@/lib/utils"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="Loading"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```
