## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@blips/ui/components/alert"
```

```tsx
<Alert>
  <InfoIcon />
  <AlertTitle>Atenção!</AlertTitle>
  <AlertDescription>
    Você pode adicionar componentes e dependências ao seu app usando a cli.
  </AlertDescription>
  <AlertAction>
    <Button size="xs" variant="outline">
      Ativar
    </Button>
  </AlertAction>
</Alert>
```

O ícone é opcional. Quando existe, ele ocupa a primeira coluna e as duas linhas do alerta; sem ícone, título e descrição usam a largura toda.

## Migrando da v2

O Alert não depende de primitiva e a API continua a mesma. O que muda:

- Novo export `AlertAction`, um slot no canto superior direito para ações como desfazer ou fechar.
- Visual mais compacto: `px-4 py-3 text-sm` virou `px-2 py-1.5 text-xs/relaxed`. O ícone padrão é `size-3.5`.
- Sem ícone, título e descrição não ficam mais presos em `col-start-2`.
- O `AlertTitle` perdeu o `line-clamp-1`: títulos longos agora quebram linha. Para manter o corte, passe `className="line-clamp-1"`.

```tsx
// v2: ação montada à mão
<Alert className="flex items-start justify-between">
  <div>
    <AlertTitle>E-mails marcados como spam.</AlertTitle>
  </div>
  <Button size="sm">Desfazer</Button>
</Alert>

// v3
<Alert>
  <AlertTitle>E-mails marcados como spam.</AlertTitle>
  <AlertAction>
    <Button size="xs">Desfazer</Button>
  </AlertAction>
</Alert>
```

## Referência da API

### Alert

O componente `Alert` exibe um destaque para chamar a atenção do usuário.

| Prop      | Tipo                         | Padrão      |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |

### AlertTitle

O componente `AlertTitle` exibe o título do alerta.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertDescription

O componente `AlertDescription` exibe a descrição ou o conteúdo do alerta.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertAction

O componente `AlertAction` exibe um elemento de ação (como um botão) posicionado de forma absoluta no canto superior direito do alerta.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
