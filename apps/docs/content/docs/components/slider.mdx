## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Slider } from "@blips/ui/components/slider"
```

```tsx
<Slider defaultValue={33} max={100} step={1} />
```

Passe um número em `value`/`defaultValue` para um único thumb, ou um array para vários. Sem `value` nem `defaultValue`, o slider desenha dois thumbs (`[min, max]`).

## Migrando da v2

A primitiva passou de Radix para [Base UI Slider](https://base-ui.com/react/components/slider).

- `value` e `defaultValue` aceitam `number` ou `number[]`. Com valor escalar, `onValueChange` recebe `number`; com array, `number[]`. O callback tem a assinatura `(value, eventDetails)`.
- **`onValueCommit` virou `onValueCommitted`.**
- Estrutura nova: Root › Control › Track › Indicator + Thumb. O antigo `Range` é o `Indicator` (continua com `data-slot="slider-range"`).
- **Atributos:** `data-orientation` continua (a lib usa as variantes `data-horizontal:`/`data-vertical:` como atalho); `data-disabled` aparece no Root e também no novo Control.
- O thumb usa `thumbAlignment="edge"` por padrão (fica dentro do trilho nas pontas).
- Visual: trilho `h-1`, thumb `size-3` com `rounded-md` e `border-ring`.

```tsx
// v2
<Slider
  defaultValue={[50]}
  onValueChange={([value]) => setVolume(value)}
  onValueCommit={([value]) => salvar(value)}
/>

// v3
<Slider
  defaultValue={50}
  onValueChange={(value) => setVolume(value as number)}
  onValueCommitted={(value) => salvar(value as number)}
/>
```
