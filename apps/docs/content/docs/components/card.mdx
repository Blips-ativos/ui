## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@blips/ui/components/card"
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Título do card</CardTitle>
    <CardDescription>Descrição do card</CardDescription>
    <CardAction>Ação do card</CardAction>
  </CardHeader>
  <CardContent>
    <p>Conteúdo do card</p>
  </CardContent>
  <CardFooter>
    <p>Rodapé do card</p>
  </CardFooter>
</Card>
```

## Migrando da v2

O Card não depende de primitiva e a API continua a mesma, com uma prop nova e um visual mais compacto:

- Nova prop `size` (`"default"` ou `"sm"`). O espaçamento vem de `--card-spacing` (16px no `default`, 12px no `sm`) em vez de `py-6`/`px-6` fixos.
- O padding caiu de 24px para 16px. `rounded-xl` virou `rounded-lg`, e a borda com sombra virou `ring-1 ring-foreground/10`.
- O card ganhou `overflow-hidden` e texto base `text-xs/relaxed`. O `CardTitle` passou para `font-heading text-sm font-medium`.

Quem sobrescrevia o padding por `className` pode ajustar a variável:

```tsx
// v2
<Card className="px-8 py-8">{/* ... */}</Card>

// v3
<Card className="[--card-spacing:--spacing(8)]">{/* ... */}</Card>
```

## Referência da API

### Card

O componente `Card` é o container raiz para o conteúdo do card.

| Prop        | Tipo                | Padrão      |
| ----------- | ------------------- | ----------- |
| `size`      | `"default" \| "sm"` | `"default"` |
| `className` | `string`            | -           |

### CardHeader

O componente `CardHeader` agrupa o título, a descrição e uma ação opcional.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### CardTitle

O componente `CardTitle` é o título do card.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### CardDescription

O componente `CardDescription` é o texto de apoio abaixo do título.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### CardAction

O componente `CardAction` posiciona conteúdo no canto superior direito do cabeçalho (por exemplo, um botão ou um badge).

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### CardContent

O componente `CardContent` é o corpo principal do card.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### CardFooter

O componente `CardFooter` reúne ações e conteúdo secundário na parte inferior do card.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |
