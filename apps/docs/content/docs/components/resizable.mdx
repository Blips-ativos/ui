## Sobre

O componente `Resizable` é construído sobre o [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) v4, de [bvaughn](https://github.com/bvaughn).

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@blips/ui/components/resizable"
```

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel defaultSize="50%">Um</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize="50%">Dois</ResizablePanel>
</ResizablePanelGroup>
```

> **Atenção:** no v4, `defaultSize`, `minSize` e `maxSize` numéricos são lidos em **pixels**. Para porcentagem, passe uma string: `defaultSize="50%"`.

## Migrando da v2

A API não mudou: continua o `react-resizable-panels` v4. A mudança é visual:

- Com `withHandle`, a alça deixa de ser uma caixinha com o ícone `DotsSixVertical` e vira uma barra fina (`h-6 w-1 rounded-lg bg-border`).
- Saiu `focus-visible:ring-offset-1` e entrou `ring-offset-background`.

## Referência da API

Consulte a documentação do [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels/tree/main/packages/react-resizable-panels).

### `react-resizable-panels` v4

Se você usa os primitives do `react-resizable-panels` diretamente, observe as mudanças do v3 para o v4 ([notas da versão 4.0.0](https://github.com/bvaughn/react-resizable-panels/releases/tag/4.0.0)):

| v3                           | v4                      |
| ---------------------------- | ----------------------- |
| `PanelGroup`                 | `Group`                 |
| `PanelResizeHandle`          | `Separator`             |
| prop `direction`             | prop `orientation`      |
| `defaultSize={50}`           | `defaultSize="50%"`     |
| `onLayout`                   | `onLayoutChange`        |
| `ImperativePanelHandle`      | `PanelImperativeHandle` |
| prop `ref` no Panel          | prop `panelRef`         |
| `data-panel-group-direction` | `aria-orientation`      |

Os wrappers da lib (`ResizablePanelGroup`, `ResizablePanel`, `ResizableHandle`) mantêm os mesmos nomes.
