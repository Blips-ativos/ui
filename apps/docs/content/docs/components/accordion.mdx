title: Accordion
description: Um conjunto de cabeçalhos interativos empilhados verticalmente, cada um revelando uma seção de conteúdo.
---

<ComponentPreview name="accordion-demo" />

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@blips/ui/components/accordion"
```

```tsx
<Accordion type="single" collapsible defaultValue="item-1">
  <AccordionItem value="item-1">
    <AccordionTrigger>É acessível?</AccordionTrigger>
    <AccordionContent>
      Sim. Segue o padrão de design WAI-ARIA.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```
