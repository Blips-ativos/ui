## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Button } from "@blips/ui/components/button"
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@blips/ui/components/popover"
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>
    Abrir popover
  </PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Título</PopoverTitle>
      <PopoverDescription>Texto de descrição aqui.</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

## Migrando da v2

A primitiva passou de Radix para [Base UI Popover](https://base-ui.com/react/components/popover).

- `asChild` saiu do `PopoverTrigger`. Use `render`.
- `onOpenChange` recebe `(open, eventDetails)`. `modal` aceita `boolean | "trap-focus"`.
- O `PopoverContent` mantém `side`, `sideOffset`, `align` e `alignOffset`, e ganha `anchor`. Saem `onOpenAutoFocus`, `onEscapeKeyDown`, `onInteractOutside`, `forceMount`, `avoidCollisions` e `collisionPadding`; para foco, use `initialFocus`/`finalFocus`.
- O `PopoverAnchor` não aceita mais `asChild`: ele é uma `<div>` que precisa ficar dentro do mesmo `<Popover>`.
- Variáveis CSS: `--radix-popover-trigger-width` vira `--anchor-width`, `--radix-popover-content-available-height` vira `--available-height` e `--radix-popover-content-transform-origin` vira `--transform-origin`. Seletores `data-[state=open]` viram `data-open`/`data-closed`.

```tsx
// v2
<PopoverTrigger asChild>
  <Button variant="outline">Abrir</Button>
</PopoverTrigger>
<PopoverContent className="w-[--radix-popover-trigger-width]" />

// v3
<PopoverTrigger render={<Button variant="outline" />}>Abrir</PopoverTrigger>
<PopoverContent className="w-(--anchor-width)" />
```

## Referência da API

### PopoverContent

| Prop          | Tipo                                     | Padrão     |
| ------------- | ---------------------------------------- | ---------- |
| `side`        | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `sideOffset`  | `number`                                 | `4`        |
| `align`       | `"start" \| "center" \| "end"`           | `"center"` |
| `alignOffset` | `number`                                 | `0`        |
| `anchor`      | `Element \| RefObject \| VirtualElement` | -          |

Para as demais props, consulte a documentação do [Base UI Popover](https://base-ui.com/react/components/popover).
