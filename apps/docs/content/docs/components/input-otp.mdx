## Sobre

O Input OTP é construído sobre o [input-otp](https://github.com/guilhermerodz/input-otp) de [@guilherme_rodz](https://twitter.com/guilherme_rodz).

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@blips/ui/components/input-otp"
```

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Padrão

Use a prop `pattern` para definir um padrão personalizado para o input OTP.

```tsx
import { REGEXP_ONLY_DIGITS_AND_CHARS } from "input-otp"

<InputOTP maxLength={6} pattern={REGEXP_ONLY_DIGITS_AND_CHARS}>
  ...
</InputOTP>
```

## Migrando da v2

A API do `input-otp` não mudou. O que muda é o visual:

- `InputOTPSlot` ficou menor: `size-7` (antes `h-9 w-9`) e texto `text-xs/relaxed`. Para slots maiores, aplique as classes pelo grupo, como no exemplo de formulário.
- **O container perdeu o `gap-2`.** Os grupos e separadores ficam colados; para espaçá-los, passe `containerClassName="gap-2"`.
- `InputOTPGroup` ganha `rounded-md` e um anel de erro quando algum filho tem `aria-invalid`.
- O `InputOTP` passa a forçar `spellCheck={false}`.

```tsx
// v3: recupera o espaçamento entre grupos da v2
<InputOTP maxLength={6} containerClassName="gap-2">
  ...
</InputOTP>
```
