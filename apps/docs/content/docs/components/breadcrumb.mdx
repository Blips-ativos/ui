## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@blips/ui/components/breadcrumb"
```

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Início</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">Componentes</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## Exemplos

### Separador personalizado

Use um componente personalizado como `children` de `<BreadcrumbSeparator />` para criar um separador customizado.

<ComponentPreview name="breadcrumb-separator" />

### Dropdown

Você pode compor `<BreadcrumbItem />` com um `<DropdownMenu />` para criar um dropdown no breadcrumb.

<ComponentPreview name="breadcrumb-dropdown" />

### Recolhido

Fornecemos um componente `<BreadcrumbEllipsis />` para mostrar um estado recolhido quando o breadcrumb fica muito longo. No exemplo, ele serve de gatilho de um `DropdownMenu` com os níveis escondidos.

<ComponentPreview name="breadcrumb-ellipsis" />

### Componente de link

Para usar o componente de link da sua biblioteca de roteamento, passe-o na prop `render` do `<BreadcrumbLink />`. O texto continua como `children`.

```tsx
import Link from "next/link"

<BreadcrumbLink render={<Link href="/" />}>Início</BreadcrumbLink>
```

## Migrando da v2

- `BreadcrumbLink`: a prop `asChild` saiu e no lugar entra `render` (`useRender` do Base UI). Os tipos agora são `useRender.ComponentProps<"a">`.
- Os ícones padrão são `CaretRightIcon` (separador) e `DotsThreeIcon` (reticências).
- Visual: `BreadcrumbList` usa `text-xs/relaxed` com `gap-1.5` fixo (sem o `sm:gap-2.5`), `BreadcrumbItem` usa `gap-1` e `BreadcrumbEllipsis` passou de `size-9` para `size-4`.

```tsx
// v2
<BreadcrumbLink asChild>
  <Link href="/componentes">Componentes</Link>
</BreadcrumbLink>

// v3
<BreadcrumbLink render={<Link href="/componentes" />}>
  Componentes
</BreadcrumbLink>
```

## Referência da API

### Breadcrumb

O componente `Breadcrumb` é o elemento de navegação raiz que envolve todos os componentes do breadcrumb.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbList

O componente `BreadcrumbList` exibe a lista ordenada de itens do breadcrumb.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbItem

O componente `BreadcrumbItem` envolve itens individuais do breadcrumb.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbLink

O componente `BreadcrumbLink` exibe um link clicável no breadcrumb. Por padrão renderiza um `<a>`; use `render` para trocar o elemento (via `useRender` do Base UI).

| Prop        | Tipo                                                   | Padrão  |
| ----------- | ------------------------------------------------------ | ------- |
| `render`    | `React.ReactElement \| ((props, state) => ReactElement)` | `<a />` |
| `className` | `string`                                               | -       |

### BreadcrumbPage

O componente `BreadcrumbPage` exibe a página atual no breadcrumb (não clicável).

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbSeparator

O componente `BreadcrumbSeparator` exibe um separador entre os itens do breadcrumb. Você pode passar children personalizados para substituir o ícone de separador padrão.

| Prop        | Tipo              | Padrão  |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |

### BreadcrumbEllipsis

O componente `BreadcrumbEllipsis` exibe um indicador de reticências para itens recolhidos do breadcrumb.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
