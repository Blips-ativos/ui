## Sobre

O Drawer é construído sobre o [Vaul](https://github.com/emilkowalski/vaul) por [emilkowalski](https://twitter.com/emilkowalski).

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@blips/ui/components/drawer"
```

```tsx
<Drawer>
  <DrawerTrigger>Abrir</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Você tem certeza absoluta?</DrawerTitle>
      <DrawerDescription>Esta ação não pode ser desfeita.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <Button>Enviar</Button>
      <DrawerClose>
        <Button variant="outline">Cancelar</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```
