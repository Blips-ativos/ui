## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@blips/ui/components/pagination"
```

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" text="Anterior" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">3</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" text="Próxima" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

`PaginationPrevious` e `PaginationNext` mostram `"Previous"` e `"Next"` por padrão. Use a prop `text` para traduzir o rótulo.

## Next.js

O `PaginationLink` é um `Button` do Base UI renderizado como `<a>` (`nativeButton={false}` e `render={<a />}`), e aceita as props de `<a>`.

Para navegar com o `<Link />` do Next.js, troque o elemento passado em `render` numa cópia local de `pagination.tsx`:

```diff
+ import Link from "next/link"

  type PaginationLinkProps = {
    isActive?: boolean
  } & Pick<React.ComponentProps<typeof Button>, "size"> &
-   React.ComponentProps<"a">
+   React.ComponentProps<typeof Link>

  // ...
      render={
-       <a
+       <Link
          aria-current={isActive ? "page" : undefined}
          data-slot="pagination-link"
          data-active={isActive}
          {...props}
        />
      }
```

## Migrando da v2

- `PaginationLink` agora renderiza `<Button nativeButton={false} render={<a />}>` (Base UI) em vez de um `<a>` com `buttonVariants`. As props de `<a>` (`href`, `onClick`…) continuam valendo, e o elemento final continua sendo um `<a>`.
- `PaginationPrevious` e `PaginationNext` ganharam a prop `text` (padrão `"Previous"`/`"Next"`) para traduzir o rótulo.
- Os ícones agora são `CaretLeftIcon`, `CaretRightIcon` e `DotsThreeIcon`, e não giram mais em RTL.
- Visual: `PaginationContent` passou de `gap-1` para `gap-0.5`, `PaginationEllipsis` de `size-9` para `size-7`, e os tamanhos vêm do `Button` da v3 (`icon` é `size-7` e `default` é `h-7`).

```tsx
// v2: rótulo fixo em inglês
<PaginationPrevious href="#" />
<PaginationNext href="#" />

// v3
<PaginationPrevious href="#" text="Anterior" />
<PaginationNext href="#" text="Próxima" />
```
