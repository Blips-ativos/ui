## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Kbd } from "@blips/ui/components/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

## Referência da API

### Kbd

Use o componente `Kbd` para exibir uma tecla do teclado.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

Use o componente `KbdGroup` para agrupar componentes `Kbd`.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
