## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Button } from "@blips/ui/components/button"
```

```tsx
<Button variant="outline">Botão</Button>
```

O `Button` é construído sobre o [Button do Base UI](https://base-ui.com/react/components/button). Ele aceita todas as props do primitivo, incluindo `render`, `nativeButton` e `focusableWhenDisabled`.

### Como link (`render`)

Use a prop `render` para renderizar o botão como outro elemento, por exemplo um `<a>` ou o `Link` do Next.js. Quando o elemento renderizado não for um `<button>` nativo, passe `nativeButton={false}`; sem isso o Base UI aplica a semântica de botão nativo e avisa no console.

<ComponentPreview name="button-render" />

```tsx
import Link from "next/link"

<Button nativeButton={false} render={<Link href="/login" />}>
  Entrar
</Button>
```

Se você só precisa do visual de botão num elemento qualquer, use `buttonVariants`:

```tsx
import { buttonVariants } from "@blips/ui/components/button"

<a href="/login" className={buttonVariants({ variant: "outline" })}>
  Entrar
</a>
```

## Referência da API

### Button

O `Button` envolve o [Button do Base UI](https://base-ui.com/react/components/button) e adiciona as variantes de estilo. As demais props são as do primitivo.

| Prop                    | Tipo                                                                                 | Padrão      |
| ----------------------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant`               | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`                  | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `render`                | `React.ReactElement \| (props, state) => React.ReactElement`                         | -           |
| `nativeButton`          | `boolean`                                                                            | `true`      |
| `focusableWhenDisabled` | `boolean`                                                                            | `false`     |
| `disabled`              | `boolean`                                                                            | `false`     |

`style` também aceita uma função que recebe o estado do botão. O `className` precisa ser string: ele passa pelo `buttonVariants`, e uma função seria descartada.

### buttonVariants

Função `cva` que devolve as classes do botão. Recebe `{ variant, size, className }`.

## Migrando da v2

- **`asChild` saiu; use `render`.** Quando o elemento renderizado não é um `<button>`, passe `nativeButton={false}`.

  ```tsx
  // v2
  <Button asChild>
    <a href="/conta">Minha conta</a>
  </Button>

  // v3
  <Button nativeButton={false} render={<a href="/conta" />}>
    Minha conta
  </Button>
  ```

- **Ícones usam `data-icon`.** O padding reduzido do lado do ícone agora depende de `data-icon="inline-start"` ou `data-icon="inline-end"` no ícone filho; o antigo `has-[>svg]:px-*` saiu.

  ```tsx
  // v2
  <Button>
    <GitBranch /> Nova branch
  </Button>

  // v3
  <Button>
    <GitBranchIcon data-icon="inline-start" /> Nova branch
  </Button>
  ```

- **Sem `data-variant` e `data-size`.** O botão não emite mais esses atributos. Quem estilizava ou testava por `[data-variant=…]` ou `[data-size=…]` precisa mudar o seletor. O `data-slot="button"` continua.
- **Props do Base UI.** O tipo agora é `ButtonPrimitive.Props` em vez de `React.ComponentProps<"button">`. Os handlers (`onClick` etc.) seguem iguais, e entra a prop `focusableWhenDisabled`.
- **Visual mais compacto.** As alturas caíram um degrau: `default` foi de `h-9` para `h-7`, `sm` de `h-8` para `h-6`, `lg` de `h-10` para `h-8`, `xs` de `h-6` para `h-5`; os tamanhos `icon-*` acompanham. O texto padrão é `text-xs/relaxed` e o espaço entre ícone e texto caiu de `gap-2` para `gap-1`.
- **`destructive` e `outline` mudaram.** `destructive` deixou de ser sólido (`bg-destructive/10 text-destructive`). `outline` perdeu o `bg-background` e o `shadow-xs`.
