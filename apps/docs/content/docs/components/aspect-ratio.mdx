```

</AspectRatio>
```

## Referência da API

### AspectRatio

O componente `AspectRatio` exibe conteúdo dentro de uma proporção desejada.

| Prop        | Type     | Default | Required |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | Sim      |
| `className` | `string` | -       | Não      |

Para mais informações, consulte a [documentação do Radix UI](https://www.radix-ui.com/primitives/docs/components/aspect-ratio#api-reference).
