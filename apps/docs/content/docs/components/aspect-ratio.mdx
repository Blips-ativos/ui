## Referência da API

### AspectRatio

Uma `<div>` com `aspect-ratio` do CSS (via a variável `--ratio`). Aceita todas as props de `<div>`. Filhos com `absolute inset-0` ou `fill` ocupam a área toda.

| Prop        | Tipo     | Padrão | Obrigatório |
| ----------- | -------- | ------ | ----------- |
| `ratio`     | `number` | -      | Sim         |
| `className` | `string` | -      | Não         |

## Migrando da v2

- **Sem primitivo**: deixou de usar o `@radix-ui/react-aspect-ratio`; agora é uma `<div>` simples, sem `asChild`. Funciona em Server Components.
- **`ratio` é obrigatória.** No Radix o padrão era `1`; sem `ratio` o código não compila.
- **DOM**: em vez de um wrapper com `padding-bottom` e uma `<div>` interna absoluta, há uma única `<div className="relative aspect-(--ratio)">`. O `className` vai direto para ela.

```tsx
// v2
<AspectRatio>
  <img src="/foto.jpg" alt="Foto" className="size-full object-cover" />
</AspectRatio>

// v3
<AspectRatio ratio={1}>
  <img src="/foto.jpg" alt="Foto" className="size-full object-cover" />
</AspectRatio>
```
