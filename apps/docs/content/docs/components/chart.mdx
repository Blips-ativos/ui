Apresentamos os **Charts**: uma coleção de componentes de gráfico que você pode copiar e colar nos seus apps.

Os gráficos foram projetados para ficar ótimos de saída. Eles funcionam bem com os outros componentes e são totalmente personalizáveis para se adequar ao seu projeto.

## Componente

Usamos o [Recharts](https://recharts.github.io/) **v3** por baixo dos panos.

Projetamos o componente `chart` pensando em composição. **Você constrói seus gráficos usando componentes do Recharts e só traz componentes customizados, como o `ChartTooltip`, quando e onde precisar**.

```tsx /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
} from "@blips/ui/components/chart"

export function MyChart() {
  return (
    <ChartContainer config={chartConfig}>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

Não fazemos wrap do Recharts. Isso significa que você não fica preso a uma abstração: quando sair uma nova versão do Recharts, basta seguir o caminho oficial de upgrade.

## Instalação

```bash
npm install @blips/ui
```

O `recharts` 3 vem como dependência da lib. Como você monta os gráficos importando do `recharts` direto, instale-o também no app, na mesma versão major:

```bash
npm install recharts@3
```

## Configuração do gráfico

A configuração do gráfico é onde você define os rótulos, os ícones e as cores.

Ela é intencionalmente desacoplada dos dados. Assim você pode compartilhar a configuração e os tokens de cor entre gráficos, e ela também funciona quando os dados ou as cores vêm de fora ou em outro formato.

```tsx /ChartConfig/
import { MonitorIcon } from "@phosphor-icons/react"

import { type ChartConfig } from "@blips/ui/components/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: MonitorIcon,
    // Uma cor como 'oklch(0.6 0.2 250)' ou 'var(--chart-1)'
    color: "var(--chart-1)",
    // OU um objeto de tema com chaves 'light' e 'dark'
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

## Temas

Os gráficos têm suporte nativo a temas. Você pode usar variáveis CSS (recomendado) ou cores em qualquer formato, como hex, hsl ou oklch.

Os tokens `--chart-1` a `--chart-5` da lib já são cores completas (oklch). Use `var(--chart-1)` direto, **sem** envolver em `hsl(...)`.

Cada chave da configuração vira uma variável `--color-<chave>` dentro do `ChartContainer`, que você usa nos componentes do Recharts: `fill="var(--color-desktop)"`.

## Tooltip

Um tooltip de gráfico tem um rótulo (label), um nome (name), um indicador (indicator) e um valor (value). Você pode combiná-los para personalizar o tooltip.

<ComponentPreview name="chart-tooltip" />

Ligue ou desligue cada parte com as props `hideLabel` e `hideIndicator`, e mude o estilo do indicador com a prop `indicator`.

Use `labelKey` e `nameKey` para usar uma chave customizada para o rótulo e o nome.

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@blips/ui/components/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### Props

| Prop             | Tipo                       | Descrição                                          |
| :--------------- | :------------------------- | :------------------------------------------------- |
| `labelKey`       | string                     | A chave de config ou de dados usada no rótulo.     |
| `nameKey`        | string                     | A chave de config ou de dados usada no nome.       |
| `indicator`      | `dot` `line` ou `dashed`   | O estilo do indicador.                             |
| `hideLabel`      | boolean                    | Oculta o rótulo.                                   |
| `hideIndicator`  | boolean                    | Oculta o indicador.                                |
| `formatter`      | função                     | Formata cada item (tipos do Recharts 3).           |
| `labelFormatter` | função                     | Formata o rótulo (tipos do Recharts 3).            |

O tooltip mostra o valor também quando ele é `0`, e valores que não são número aparecem via `String()`.

## Acessibilidade

No Recharts 3 a camada de acessibilidade (`accessibilityLayer`) já vem **ligada por padrão**: os gráficos têm navegação por teclado e suporte a leitores de tela sem configuração. Para desligá-la, passe `accessibilityLayer={false}`.

```tsx title="components/example-chart.tsx"
<LineChart accessibilityLayer={false} />
```

## Renderização inicial

O `ChartContainer` usa o `ResponsiveContainer` do Recharts. Antes de medir o elemento (por exemplo, na renderização no servidor), ele usa a prop `initialDimension`, com padrão `{ width: 320, height: 200 }`.

```tsx
<ChartContainer config={chartConfig} initialDimension={{ width: 600, height: 300 }}>
  ...
</ChartContainer>
```

## Migrando da v2

A v3 da lib exige o **Recharts 3**. A API do componente é a mesma; o que muda vem do Recharts.

- Siga o [guia de migração do Recharts 3](https://github.com/recharts/recharts/wiki/3.x-migration-guide) para o código que usa o Recharts direto: `Customized` deixou de ser necessário (componentes customizados entram direto no gráfico), `activeIndex` saiu (use `defaultIndex` no `Tooltip`), e os tipos de payload do `Tooltip` e da `Legend` mudaram.
- `accessibilityLayer` agora vem ligado por padrão. Não precisa mais passar a prop.
- `ChartTooltipContent` usa os tipos `DefaultTooltipContentProps` do Recharts 3, e `ChartLegendContent` recebe `DefaultLegendContentProps`. Um `formatter`/`labelFormatter` tipado contra o Recharts 2 pode precisar de ajuste.
- `ChartContainer` ganhou a prop opcional `initialDimension`.
- O tooltip passa a mostrar valores `0`, e a classe do container mudou de `min-w-[8rem] text-xs` para `min-w-32 text-xs/relaxed`.
- Os tokens de cor da lib são oklch: troque `hsl(var(--chart-1))` por `var(--chart-1)`.

```tsx
// v2 (Recharts 2)
const chartConfig = {
  desktop: { label: "Desktop", color: "hsl(var(--chart-1))" },
} satisfies ChartConfig

<BarChart accessibilityLayer data={chartData}>
  <Customized component={<MinhaMarca />} />
</BarChart>

// v3 (Recharts 3)
const chartConfig = {
  desktop: { label: "Desktop", color: "var(--chart-1)" },
} satisfies ChartConfig

<BarChart data={chartData}>
  <MinhaMarca />
</BarChart>
```
