## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Button } from "@blips/ui/components/button"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@blips/ui/components/dropdown-menu"
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="outline" />}>
    Abrir
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuGroup>
      <DropdownMenuLabel>Minha conta</DropdownMenuLabel>
      <DropdownMenuItem onClick={abrirPerfil}>Perfil</DropdownMenuItem>
      <DropdownMenuItem>Faturamento</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuItem>Equipe</DropdownMenuItem>
      <DropdownMenuItem>Assinatura</DropdownMenuItem>
    </DropdownMenuGroup>
  </DropdownMenuContent>
</DropdownMenu>
```

O `DropdownMenuTrigger` renderiza o próprio `<button>`: passe o `Button` pela prop `render`, nunca como filho. O `DropdownMenuLabel` precisa ficar dentro de um `DropdownMenuGroup`.

## Migrando da v2

A primitiva passou de Radix Dropdown Menu para [Base UI Menu](https://base-ui.com/react/components/menu).

- `asChild` saiu do trigger e de todos os itens. Use `render`.
- `onSelect` vira `onClick`. Para manter o menu aberto depois do clique (o antigo `event.preventDefault()`), use `closeOnClick={false}` no item.
- `onCheckedChange` do `DropdownMenuCheckboxItem` recebe `(checked: boolean, eventDetails)`. Não existe mais o estado `"indeterminate"`.
- `onValueChange` do `DropdownMenuRadioGroup` recebe `(value, eventDetails)`.
- O `align` padrão do `DropdownMenuContent` passou de `"center"` para `"start"`. Saem `avoidCollisions`, `collisionPadding`, `onCloseAutoFocus`, `onEscapeKeyDown` e `forceMount`.
- `DropdownMenuContent` e `DropdownMenuSubContent` já incluem o portal: não os envolva em `DropdownMenuPortal`.
- `DropdownMenuLabel` precisa estar dentro de um `DropdownMenuGroup`.
- Seletores `data-[state=open]` viram `data-open` (e `data-popup-open` no trigger); `data-[state=checked]` vira `data-checked`.
- O indicador de checkbox e radio mudou da esquerda para a direita.

```tsx
// v2
<DropdownMenuTrigger asChild>
  <Button variant="ghost">Ações</Button>
</DropdownMenuTrigger>
<DropdownMenuContent>
  <DropdownMenuLabel>Conta</DropdownMenuLabel>
  <DropdownMenuItem onSelect={(e) => { e.preventDefault(); copiar() }}>
    Copiar
  </DropdownMenuItem>
</DropdownMenuContent>

// v3
<DropdownMenuTrigger render={<Button variant="ghost" />}>Ações</DropdownMenuTrigger>
<DropdownMenuContent>
  <DropdownMenuGroup>
    <DropdownMenuLabel>Conta</DropdownMenuLabel>
    <DropdownMenuItem closeOnClick={false} onClick={copiar}>
      Copiar
    </DropdownMenuItem>
  </DropdownMenuGroup>
</DropdownMenuContent>
```

## Referência da API

### DropdownMenuContent

| Prop          | Tipo                                     | Padrão     |
| ------------- | ---------------------------------------- | ---------- |
| `side`        | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `sideOffset`  | `number`                                 | `4`        |
| `align`       | `"start" \| "center" \| "end"`           | `"start"`  |
| `alignOffset` | `number`                                 | `0`        |

### DropdownMenuItem

| Prop      | Tipo                         | Padrão      |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `inset`   | `boolean`                    | -           |

Consulte a documentação do [Base UI Menu](https://base-ui.com/react/components/menu) para a referência completa da API.
