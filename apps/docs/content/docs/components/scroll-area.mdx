## Instalação

```bash

```

## Uso

```tsx
import { ScrollArea } from "@blips/ui/components/scroll-area"
```

```tsx
<ScrollArea className="h-[200px] w-[350px] rounded-md border p-4">
  Seu conteúdo rolável aqui.
</ScrollArea>
```
