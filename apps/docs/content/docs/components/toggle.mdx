## Uso

```tsx
import { Toggle } from "@blips/ui/components/toggle"
```

```tsx
<Toggle aria-label="Alternar negrito">
  <TextBIcon />
</Toggle>
```

## Referência da API

### Toggle

Aceita todas as props do `Toggle` do Base UI.

| Prop              | Tipo                                           | Padrão      |
| ----------------- | ---------------------------------------------- | ----------- |
| `variant`         | `"default" \| "outline"`                       | `"default"` |
| `size`            | `"default" \| "sm" \| "lg"`                    | `"default"` |
| `pressed`         | `boolean`                                      | -           |
| `defaultPressed`  | `boolean`                                      | `false`     |
| `onPressedChange` | `(pressed: boolean, eventDetails) => void`     | -           |
| `disabled`        | `boolean`                                      | `false`     |
| `render`          | `React.ReactElement \| (props, state) => React.ReactElement` | - |

Consulte a documentação do [Base UI Toggle](https://base-ui.com/react/components/toggle).

## Migrando da v2

- **Primitivo**: Radix trocado pelo `Toggle` do Base UI. `pressed`, `defaultPressed` e `onPressedChange` continuam, mas o callback ganhou um 2º argumento (`eventDetails`).
- **Estado no DOM**: o estado ligado agora é `data-pressed` / `aria-pressed`, não mais `data-state="on"`. Atualize CSS e testes que usavam `data-[state=on]`.
- **`asChild` não existe**: use `render`.
- **Visual**: alturas menores (`default` `h-7`, `sm` `h-6`, `lg` `h-8`) e o estado ligado usa `bg-muted`.

```tsx
// v2
<Toggle className="data-[state=on]:text-primary">
  <TextB />
</Toggle>

// v3
<Toggle className="aria-pressed:text-primary">
  <TextBIcon />
</Toggle>
```
