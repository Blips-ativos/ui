---
title: Tooltip
description: Um popup que exibe informações relacionadas a um elemento quando o elemento recebe foco do teclado ou o mouse passa sobre ele.
---

<ComponentPreview name="tooltip-demo" />

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@blips/ui/components/tooltip"
```

```tsx
<Tooltip>
  <TooltipTrigger>Passe o mouse</TooltipTrigger>
  <TooltipContent>
    <p>Adicionar à biblioteca</p>
  </TooltipContent>
</Tooltip>
```
