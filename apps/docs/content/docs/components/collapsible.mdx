## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@blips/ui/components/collapsible"
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Posso usar isso no meu projeto?</CollapsibleTrigger>
  <CollapsibleContent>
    Sim. Livre para uso em projetos pessoais e comerciais. Nenhuma atribuição
    necessária.
  </CollapsibleContent>
</Collapsible>
```

Para usar outro elemento como gatilho, passe-o em `render`:

```tsx
<CollapsibleTrigger render={<Button variant="ghost" size="icon" />}>
  <CaretUpDownIcon />
</CollapsibleTrigger>
```

## Estado controlado

Use as props `open` e `onOpenChange` para controlar o estado.

```tsx
import * as React from "react"

export function Example() {
  const [open, setOpen] = React.useState(false)

  return (
    <Collapsible open={open} onOpenChange={setOpen}>
      <CollapsibleTrigger>Alternar</CollapsibleTrigger>
      <CollapsibleContent>Conteúdo</CollapsibleContent>
    </Collapsible>
  )
}
```

## Migrando da v2

- `asChild` no `CollapsibleTrigger` virou `render`.
- `CollapsibleContent` agora é um `Collapsible.Panel`: `forceMount` virou `keepMounted`, e entrou `hiddenUntilFound`.
- Atributos de estado: `data-state="open" | "closed"` virou `data-open` / `data-closed` no painel e `data-panel-open` no trigger. Seletores como `group-data-[state=open]:` precisam virar `group-data-panel-open:` (ou `data-open:` no painel).
- A variável para animar a altura passou de `--radix-collapsible-content-height` para `--collapsible-panel-height`.
- `onOpenChange` recebe um segundo argumento, `eventDetails`.

```tsx
// v2
<CollapsibleTrigger asChild>
  <Button variant="ghost" className="group">
    <CaretRight className="group-data-[state=open]:rotate-90" />
  </Button>
</CollapsibleTrigger>

// v3
<CollapsibleTrigger render={<Button variant="ghost" className="group" />}>
  <CaretRightIcon className="group-data-panel-open:rotate-90" />
</CollapsibleTrigger>
```
