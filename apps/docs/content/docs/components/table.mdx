## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@blips/ui/components/table"
```

```tsx
<Table>
  <TableCaption>Uma lista das suas faturas recentes.</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead className="w-[100px]">Fatura</TableHead>
      <TableHead>Status</TableHead>
      <TableHead>Forma de pagamento</TableHead>
      <TableHead className="text-right">Valor</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell className="font-medium">FAT001</TableCell>
      <TableCell>Pago</TableCell>
      <TableCell>Cartão de crédito</TableCell>
      <TableCell className="text-right">R$ 250,00</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

Para ordenação, filtros e paginação, combine o `Table` com o [TanStack Table](https://tanstack.com/table).

## Migrando da v2

A API não mudou (os componentes continuam sendo elementos HTML estilizados). O que muda é o visual:

- A fonte de `Table` e `TableCaption` caiu de `text-sm` para `text-xs`.
- `TableHead` e `TableCell` perderam `[&>[role=checkbox]]:translate-y-[2px]`. Checkboxes na tabela podem precisar desse ajuste local.
- `TableRow` ganhou `has-aria-expanded:bg-muted/50`: a linha com conteúdo expandido fica destacada.

```tsx
// Para recuperar o alinhamento antigo do checkbox
<TableCell className="[&>[role=checkbox]]:translate-y-[2px]">
  <Checkbox />
</TableCell>
```
