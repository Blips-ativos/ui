## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@blips/ui/components/avatar"
```

```tsx
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Referência da API

### Avatar

O componente `Avatar` é o componente raiz que envolve a imagem do avatar e o fallback. Aceita todas as props do `Avatar.Root` do Base UI.

| Prop        | Tipo                        | Padrão      |
| ----------- | --------------------------- | ----------- |
| `size`      | `"default" \| "sm" \| "lg"` | `"default"` |
| `className` | `string`                    | -           |

### AvatarImage

O componente `AvatarImage` exibe a imagem do avatar. Ele aceita todas as props do `Avatar.Image` do Base UI, incluindo `onLoadingStatusChange` (`"idle" | "loading" | "loaded" | "error"`).

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `src`       | `string` | -       |
| `alt`       | `string` | -       |
| `className` | `string` | -       |

### AvatarFallback

O componente `AvatarFallback` exibe um fallback quando a imagem falha ao carregar. Ele aceita todas as props do `Avatar.Fallback` do Base UI.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `delay`     | `number` | -       |
| `className` | `string` | -       |

### AvatarBadge

O componente `AvatarBadge` exibe um indicador de badge no avatar, normalmente posicionado no canto inferior direito.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroup

O componente `AvatarGroup` exibe um grupo de avatares com estilo sobreposto.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroupCount

O componente `AvatarGroupCount` exibe um indicador de contagem em um grupo de avatares, normalmente mostrando o número de avatares adicionais.

| Prop        | Tipo     | Padrão  |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

Para mais informações sobre as props, consulte a [documentação do Base UI](https://base-ui.com/react/components/avatar).

## Migrando da v2

- **Primitivo**: Radix trocado pelo `Avatar` do Base UI. As props de `Avatar`, `AvatarImage` e `AvatarFallback` passam a ser as do Base UI.
- **`delayMs` virou `delay`** em `AvatarFallback`.
- **`asChild` não existe**: use `render` para trocar o elemento.
- **Visual**: o `Avatar` perdeu `overflow-hidden` e ganhou um anel interno via `::after`. `AvatarImage` agora é `rounded-full object-cover`.

```tsx
// v2
<AvatarFallback delayMs={600}>CN</AvatarFallback>

// v3
<AvatarFallback delay={600}>CN</AvatarFallback>
```
