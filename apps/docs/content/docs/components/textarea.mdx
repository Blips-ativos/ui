## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Textarea } from "@blips/ui/components/textarea"
```

```tsx
<Textarea />
```

## Exemplos

### Desabilitado

Use a prop `disabled` para desabilitar o textarea. Para estilizar o estado desabilitado, adicione o atributo `data-disabled` ao componente `Field`.
