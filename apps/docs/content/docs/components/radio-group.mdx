## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Field, FieldLabel } from "@blips/ui/components/field"
import { RadioGroup, RadioGroupItem } from "@blips/ui/components/radio-group"
```

```tsx
<RadioGroup defaultValue="opcao-um">
  <Field orientation="horizontal">
    <RadioGroupItem value="opcao-um" id="opcao-um" />
    <FieldLabel htmlFor="opcao-um">Opção um</FieldLabel>
  </Field>
  <Field orientation="horizontal">
    <RadioGroupItem value="opcao-dois" id="opcao-dois" />
    <FieldLabel htmlFor="opcao-dois">Opção dois</FieldLabel>
  </Field>
</RadioGroup>
```

## Migrando da v2

A primitiva passou de Radix para [Base UI Radio Group](https://base-ui.com/react/components/radio-group).

- `onValueChange` recebe `(value: unknown, eventDetails)`: o valor não é mais tipado como `string`, então pode ser preciso um cast. O `value` do item aceita qualquer tipo.
- **Atributos de estado:** `data-state="checked" | "unchecked"` vira `data-checked` e `data-unchecked`.
- `asChild` vira `render`.
- Visual: o item marcado fica preenchido (`bg-primary`, com um ponto em `primary-foreground` no centro), em vez da borda com bolinha. O `RadioGroup` ganhou `w-full`; use `className="w-fit"` se precisar do tamanho anterior.

```tsx
// v2
<RadioGroup onValueChange={(value) => setPlano(value)}>...</RadioGroup>

// v3
<RadioGroup onValueChange={(value) => setPlano(value as string)}>...</RadioGroup>
```
