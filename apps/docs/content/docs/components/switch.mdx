## Migrando da v2

A primitiva passou de Radix para [Base UI Switch](https://base-ui.com/react/components/switch).

- `onCheckedChange` recebe `(checked, eventDetails)`.
- **Atributos de estado:** `data-state="checked" | "unchecked"` vira `data-checked` e `data-unchecked`; o estado desabilitado vira `data-disabled`.
- O elemento raiz é um `<span role="switch">` com um `<input>` oculto, não mais um `<button>`.
- `asChild` vira `render`.
- A prop `size` continua. Visual menor (padrão 28 × 16,6 px, thumb `size-3.5`), foco `ring-2` e estilo para `aria-invalid`.

```tsx
// v2
<Switch className="data-[state=checked]:bg-green-600" />

// v3
<Switch className="data-checked:bg-green-600" />
```
