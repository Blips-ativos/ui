## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Skeleton } from "@blips/ui/components/skeleton"
```

```tsx
<Skeleton className="h-[20px] w-[100px] rounded-full" />
```

## Referência da API

### Skeleton

Aceita todas as props de uma `<div>`. Expõe `data-slot="skeleton"`.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

## Migrando da v2

A API não mudou. Só o visual: o fundo passou de `bg-accent` para `bg-muted`.
