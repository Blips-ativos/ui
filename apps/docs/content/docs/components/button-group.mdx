## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@blips/ui/components/button-group"
```

```tsx
<ButtonGroup>
  <Button variant="outline">Botão 1</Button>
  <Button variant="outline">Botão 2</Button>
</ButtonGroup>
```

## Acessibilidade

- O componente `ButtonGroup` tem o atributo `role` definido como `group`.
- Use `Tab` para navegar entre os botões do grupo.
- Use `aria-label` ou `aria-labelledby` para rotular o grupo de botões.

```tsx
<ButtonGroup aria-label="Formatação de texto">
  <Button variant="outline">Negrito</Button>
  <Button variant="outline">Itálico</Button>
</ButtonGroup>
```

## ButtonGroup vs ToggleGroup

- Use o componente `ButtonGroup` quando quiser agrupar botões que executam uma ação.
- Use o componente `ToggleGroup` quando quiser agrupar botões que alternam um estado.

## Referência da API

### ButtonGroup

O componente `ButtonGroup` é um contêiner que agrupa botões relacionados com estilização consistente. O arredondamento das pontas e a emenda das bordas valem para os filhos que têm `data-slot` (todos os componentes da `@blips/ui` têm).

| Prop          | Tipo                         | Padrão         |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

```tsx
<ButtonGroup>
  <Button>Botão 1</Button>
  <Button>Botão 2</Button>
</ButtonGroup>
```

Aninhe múltiplos grupos de botões para criar layouts elaborados com espaçamento. Veja o exemplo [aninhado](#aninhado) para mais detalhes.

```tsx
<ButtonGroup>
  <ButtonGroup />
  <ButtonGroup />
</ButtonGroup>
```

### ButtonGroupSeparator

O componente `ButtonGroupSeparator` divide visualmente os botões dentro de um grupo. Ele é construído sobre o [Separator do Base UI](https://base-ui.com/react/components/separator).

| Prop          | Tipo                         | Padrão       |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |

```tsx
<ButtonGroup>
  <Button>Botão 1</Button>
  <ButtonGroupSeparator />
  <Button>Botão 2</Button>
</ButtonGroup>
```

### ButtonGroupText

Use este componente para exibir texto dentro de um grupo de botões. Ele renderiza um `div` com `data-slot="button-group-text"`.

| Prop     | Tipo                                                         | Padrão |
| -------- | ------------------------------------------------------------ | ------ |
| `render` | `React.ReactElement \| (props, state) => React.ReactElement` | -      |

```tsx
<ButtonGroup>
  <ButtonGroupText>Texto</ButtonGroupText>
  <Button>Botão</Button>
</ButtonGroup>
```

Use a prop `render` para renderizar um componente personalizado como texto, por exemplo um label.

```tsx
import { ButtonGroup, ButtonGroupText } from "@blips/ui/components/button-group"
import { Input } from "@blips/ui/components/input"
import { Label } from "@blips/ui/components/label"

export function ButtonGroupTextDemo() {
  return (
    <ButtonGroup>
      <ButtonGroupText render={<Label htmlFor="name" />}>Texto</ButtonGroupText>
      <Input placeholder="Digite algo aqui..." id="name" />
    </ButtonGroup>
  )
}
```

## Migrando da v2

- **`asChild` de `ButtonGroupText` saiu; use `render`.**

  ```tsx
  // v2
  <ButtonGroupText asChild>
    <Label htmlFor="name">Texto</Label>
  </ButtonGroupText>

  // v3
  <ButtonGroupText render={<Label htmlFor="name" />}>Texto</ButtonGroupText>
  ```

- **Gatilhos de menu e popover dentro do grupo usam `render`.** Isso vem dos componentes do Base UI (`DropdownMenuTrigger`, `PopoverTrigger`, `TooltipTrigger`), não do `ButtonGroup`:

  ```tsx
  // v2
  <DropdownMenuTrigger asChild>
    <Button variant="outline" size="icon"><CaretDown /></Button>
  </DropdownMenuTrigger>

  // v3
  <DropdownMenuTrigger render={<Button variant="outline" size="icon" />}>
    <CaretDownIcon />
  </DropdownMenuTrigger>
  ```

- **Separador do Base UI.** O `ButtonGroupSeparator` usa o `Separator` do Base UI, que continua emitindo `data-orientation`. Seletores `data-[orientation=vertical]:…` seguem valendo; `data-vertical:…` e `data-horizontal:…` são atalhos da lib para o mesmo atributo.
- **Pontas por `data-slot`.** O arredondamento agora mira filhos com `data-slot` em vez de `:first-child` e `:last-child`. Um filho customizado sem `data-slot` mantém o próprio raio e não entra na emenda das bordas.
- **`ButtonGroupText` ganhou `data-slot="button-group-text"`** e ficou com `px-2.5 text-xs/relaxed`, sem `shadow-xs`.
