## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Input } from "@blips/ui/components/input"
```

```tsx
<Input type="email" placeholder="E-mail" />
```

O `Input` renderiza o [Input do Base UI](https://base-ui.com/react/components/input) e aceita todas as props de um `<input>` nativo. Para rótulo, descrição e erro, componha com o [`Field`](/docs/components/field).

## Migrando da v2

A API não mudou: o `Input` continua recebendo as props de `<input>`. O que muda:

- Agora renderiza o `Input` do [Base UI](https://base-ui.com/react/components/input) em vez de um `<input>` puro, o que integra o componente ao `Field` do Base UI.
- Densidade menor: altura `h-7` (antes `h-9`), `px-2` (antes `px-3`) e texto `text-xs/relaxed` a partir de `md` (antes `text-sm`).
- Sem `shadow-xs`; fundo `bg-input/20`; o anel de foco passa a `ring-2 ring-ring/30` e o estado `aria-invalid` ganha anel próprio.

Se você dependia da altura antiga para alinhar com outros elementos, passe `className="h-9"`.

Consulte a documentação do [Base UI Input](https://base-ui.com/react/components/input) para mais informações.
