<ComponentPreview name="input-demo" />

## Instalação

```bash
pnpm add @blips/ui
```

## Uso

```tsx
import { Input } from "@blips/ui/components/input"
```

```tsx
<Input />
```

## Exemplos

### Disabled

Use a prop `disabled` para desabilitar o input. Para estilizar o estado desabilitado, adicione o atributo `data-disabled` ao componente `Field`.

<ComponentPreview name="input-disabled" />

### File

Use a prop `type="file"` para criar um input de arquivo.
