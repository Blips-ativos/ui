## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@blips/ui/components/navigation-menu"
```

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Item um</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink href="/docs">Link</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

O conteúdo de cada item sempre abre dentro de um popup posicionado abaixo da lista. Use a prop `align` do `NavigationMenu` (`"start"` por padrão) para alinhar esse popup.

## Componente de link

Use a prop `render` para compor um componente de link customizado, como o `Link` do Next.js.

```tsx
import Link from "next/link"

import {
  NavigationMenuItem,
  NavigationMenuLink,
  navigationMenuTriggerStyle,
} from "@blips/ui/components/navigation-menu"

export function NavigationMenuDemo() {
  return (
    <NavigationMenuItem>
      <NavigationMenuLink
        render={<Link href="/docs" />}
        className={navigationMenuTriggerStyle()}
      >
        Documentação
      </NavigationMenuLink>
    </NavigationMenuItem>
  )
}
```

## Migrando da v2

A primitiva passou de Radix para [Base UI Navigation Menu](https://base-ui.com/react/components/navigation-menu).

- `asChild` saiu do `NavigationMenuLink` e do `NavigationMenuTrigger`. Use `render`. A prop `active` do link continua valendo.
- A prop `viewport` do `NavigationMenu` está **obsoleta e não tem efeito**. O conteúdo sempre aparece no popup posicionado; o modo `viewport={false}` da v2, com o conteúdo logo abaixo do item, deixou de existir.
- O `NavigationMenu` ganhou `align`, repassado ao `NavigationMenuPositioner` que ele já renderiza. `NavigationMenuPositioner` e `NavigationMenuViewport` são exportados para quem monta o root direto com o primitivo do Base UI; dentro do `NavigationMenu` da lib eles duplicam o popup.
- `value`/`onValueChange` do root recebem `(value, eventDetails)`. `delayDuration` e `skipDelayDuration` viram `delay` e `closeDelay`.
- Seletores `data-[state=open]` viram `data-popup-open`/`data-open`.

```tsx
// v2
<NavigationMenu viewport={false}>
  {/* ... */}
  <NavigationMenuLink asChild>
    <Link href="/docs">Documentação</Link>
  </NavigationMenuLink>
</NavigationMenu>

// v3
<NavigationMenu>
  {/* ... */}
  <NavigationMenuLink render={<Link href="/docs" />}>
    Documentação
  </NavigationMenuLink>
</NavigationMenu>
```

## Referência da API

### NavigationMenu

| Prop    | Tipo                           | Padrão    |
| ------- | ------------------------------ | --------- |
| `align` | `"start" \| "center" \| "end"` | `"start"` |

Consulte a documentação do [Base UI Navigation Menu](https://base-ui.com/react/components/navigation-menu) para mais informações.
