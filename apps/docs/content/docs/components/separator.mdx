## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Separator } from "@blips/ui/components/separator"
```

```tsx
<Separator />
<Separator orientation="vertical" />
```

## Referência da API

### Separator

Aceita todas as props do `Separator` do Base UI.

| Prop          | Tipo                         | Padrão         |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `className`   | `string \| (state) => string` | -             |
| `render`      | `React.ReactElement \| (props, state) => React.ReactElement` | - |

Consulte a documentação do [Base UI Separator](https://base-ui.com/react/components/separator).

## Migrando da v2

- **`decorative` foi removida.** No Base UI o separador é sempre semântico (`role="separator"` + `aria-orientation`). Para um separador puramente visual, passe `role="none"` ou `aria-hidden`.
- **Atributos de estado**: `data-[orientation=horizontal|vertical]` virou `data-horizontal` / `data-vertical`.
- **Vertical** usa `self-stretch` em vez de `h-full`.
- **`asChild` não existe**: use `render`.

```tsx
// v2
<Separator decorative className="data-[orientation=vertical]:mx-2" />

// v3
<Separator role="none" className="data-vertical:mx-2" />
```
