---
title: Toggle Group
description: Um conjunto de botões de dois estados que podem ser alternados entre ligado e desligado.
---

<ComponentPreview name="toggle-group-demo" />

## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { ToggleGroup, ToggleGroupItem } from "@blips/ui/components/toggle-group"
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```
