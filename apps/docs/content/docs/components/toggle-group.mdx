## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { ToggleGroup, ToggleGroupItem } from "@blips/ui/components/toggle-group"
```

```tsx
<ToggleGroup defaultValue={["a"]}>
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

A seleção é única por padrão. Para permitir vários itens ligados, passe `multiple`. Em ambos os modos `value`, `defaultValue` e `onValueChange` trabalham com **array**.

## Referência da API

### ToggleGroup

Aceita todas as props do `ToggleGroup` do Base UI.

| Prop            | Tipo                                         | Padrão         |
| --------------- | -------------------------------------------- | -------------- |
| `multiple`      | `boolean`                                    | `false`        |
| `value`         | `string[]`                                   | -              |
| `defaultValue`  | `string[]`                                   | -              |
| `onValueChange` | `(value: string[], eventDetails) => void`    | -              |
| `variant`       | `"default" \| "outline"`                     | `"default"`    |
| `size`          | `"default" \| "sm" \| "lg"`                  | `"default"`    |
| `spacing`       | `number`                                     | `2`            |
| `orientation`   | `"horizontal" \| "vertical"`                 | `"horizontal"` |
| `loopFocus`     | `boolean`                                    | `true`         |
| `disabled`      | `boolean`                                    | `false`        |

### ToggleGroupItem

Aceita todas as props do `Toggle` do Base UI. A prop `value` é obrigatória para o item participar do grupo.

Consulte a documentação do [Base UI Toggle Group](https://base-ui.com/react/components/toggle-group).

## Migrando da v2

- **`type` foi removida.** Seleção única é o padrão; para várias, use a prop booleana `multiple`.
- **`value` e `defaultValue` são sempre array**, também no modo único. `onValueChange` recebe `(value: string[], eventDetails)`.
- **`rovingFocus` e `loop`** viraram `loopFocus`.
- **`spacing` padrão mudou de `0` para `2`**: os itens saem separados. Para o visual grudado de antes, passe `spacing={0}`.
- **Estado do item**: `data-pressed` / `aria-pressed` no lugar de `data-state="on"`.
- **Nova prop `orientation`** para grupos verticais.

```tsx
// v2
<ToggleGroup type="single" value={align} onValueChange={setAlign}>
  <ToggleGroupItem value="left">Esquerda</ToggleGroupItem>
  <ToggleGroupItem value="right">Direita</ToggleGroupItem>
</ToggleGroup>

// v3
<ToggleGroup
  spacing={0}
  value={[align]}
  onValueChange={(value) => setAlign(value[0])}
>
  <ToggleGroupItem value="left">Esquerda</ToggleGroupItem>
  <ToggleGroupItem value="right">Direita</ToggleGroupItem>
</ToggleGroup>
```
