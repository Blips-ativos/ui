## Uso

```tsx
import { Checkbox } from "@blips/ui/components/checkbox"
```

```tsx
<Checkbox />
```

## Estado marcado

Use `defaultChecked` para checkboxes não controlados, ou `checked` e
`onCheckedChange` para controlar o estado.

```tsx
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}
```

## Migrando da v2

A primitiva passou de Radix para [Base UI Checkbox](https://base-ui.com/react/components/checkbox).

- **`checked="indeterminate"` deixou de existir.** `checked` é só `boolean`, e o estado misto vem da prop separada `indeterminate`.
- `onCheckedChange` recebe `(checked: boolean, eventDetails)`. Antes o valor podia ser `"indeterminate"`.
- **Atributos de estado:** `data-state="checked" | "unchecked" | "indeterminate"` vira `data-checked`, `data-unchecked` e `data-indeterminate`. Seletores como `peer-data-[state=checked]:` passam a `peer-data-checked:`.
- O elemento raiz é um `<span role="checkbox">` com um `<input>` oculto, não mais um `<button>`. Para formulários nativos, use `name`, `value` e `required` no `Checkbox`.
- `asChild` vira `render`.
- Visual: foco `ring-2 ring-ring/30`, sem `shadow-xs`, e uma área de toque ampliada (`after:-inset-*`).

```tsx
// v2
<Checkbox
  checked={someChecked ? "indeterminate" : allChecked}
  onCheckedChange={(value) => setAll(value === true)}
/>
<label className="peer-data-[state=checked]:line-through">Tarefa</label>

// v3
<Checkbox
  checked={allChecked}
  indeterminate={someChecked}
  onCheckedChange={(checked) => setAll(checked)}
/>
<label className="peer-data-checked:line-through">Tarefa</label>
```
