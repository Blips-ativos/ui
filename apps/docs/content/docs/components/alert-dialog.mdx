## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@blips/ui/components/alert-dialog"
import { Button } from "@blips/ui/components/button"
```

```tsx
const [open, setOpen] = React.useState(false)

<AlertDialog open={open} onOpenChange={setOpen}>
  <AlertDialogTrigger render={<Button variant="outline" />}>
    Mostrar diálogo
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Você tem certeza absoluta?</AlertDialogTitle>
      <AlertDialogDescription>
        Esta ação não pode ser desfeita. Isso excluirá permanentemente sua conta
        dos nossos servidores.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancelar</AlertDialogCancel>
      <AlertDialogAction
        onClick={async () => {
          await excluirConta()
          setOpen(false)
        }}
      >
        Continuar
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

O `AlertDialogCancel` fecha o diálogo. O `AlertDialogAction` é um `Button` comum e **não fecha sozinho**: controle `open` e feche no `onClick`, depois de concluir a ação.

## Migrando da v2

A primitiva passou de Radix para [Base UI Alert Dialog](https://base-ui.com/react/components/alert-dialog).

- `asChild` saiu do `AlertDialogTrigger`. Use `render`.
- **Mudança de comportamento:** o `AlertDialogAction` não fecha mais o diálogo. Controle `open`/`onOpenChange` e feche no `onClick`.
- `AlertDialogAction` aceita as props do `Button` (`variant`, `size`, `render`). `AlertDialogCancel` continua aceitando `variant` e `size` (padrão `outline`), mas não aceita `asChild`.
- `AlertDialogContent` perde as props do Radix (`onEscapeKeyDown`, `onOpenAutoFocus`, `onCloseAutoFocus`, `forceMount`).
- `onOpenChange` recebe `(open, eventDetails)`. Seletores `data-[state=*]` viram `data-open` e `data-closed`.
- Tamanhos menores: `default` vai até `sm:max-w-sm` (antes `sm:max-w-lg`) e `sm` até `max-w-64`. O `AlertDialogMedia` caiu de `size-16` para `size-8`.

```tsx
// v2
<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="outline">Excluir</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    {/* ... */}
    <AlertDialogAction onClick={excluir}>Excluir</AlertDialogAction>
  </AlertDialogContent>
</AlertDialog>

// v3
<AlertDialog open={open} onOpenChange={setOpen}>
  <AlertDialogTrigger render={<Button variant="outline" />}>
    Excluir
  </AlertDialogTrigger>
  <AlertDialogContent>
    {/* ... */}
    <AlertDialogAction
      onClick={async () => {
        await excluir()
        setOpen(false)
      }}
    >
      Excluir
    </AlertDialogAction>
  </AlertDialogContent>
</AlertDialog>
```

## Referência da API

### AlertDialogContent

| Prop   | Tipo                | Padrão      |
| ------ | ------------------- | ----------- |
| `size` | `"default" \| "sm"` | `"default"` |

### AlertDialogCancel

| Prop      | Tipo                              | Padrão      |
| --------- | --------------------------------- | ----------- |
| `variant` | `ButtonProps["variant"]`          | `"outline"` |
| `size`    | `ButtonProps["size"]`             | `"default"` |

Para mais informações sobre os outros componentes e suas props, consulte a documentação do [Base UI Alert Dialog](https://base-ui.com/react/components/alert-dialog).
