## Referência da API

### Label

Um `<label>` nativo estilizado: aceita todas as props de `<label>`. O Base UI não tem um primitivo de Label; a associação com o controle é feita por `htmlFor` ou aninhando o controle dentro do label.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `htmlFor`   | `string` | -      |
| `className` | `string` | -      |

Em formulários, prefira o [`Field`](/docs/components/field) com `FieldLabel`, que já cuida do layout e dos estados.

## Migrando da v2

- **Elemento nativo**: o `Label` deixou de usar o `@radix-ui/react-label` e agora é um `<label>`.
- **`asChild` foi removida** e não há `render`: use o `<label>` direto ou envolva o controle.
- O Radix impedia a seleção de texto em duplo clique; isso deixou de existir (a classe `select-none` continua).
- **Visual**: fonte padrão passou de `text-sm` para `text-xs/relaxed`.

```tsx
// v2
<Label asChild>
  <span>E-mail</span>
</Label>

// v3
<Label htmlFor="email">E-mail</Label>
```
