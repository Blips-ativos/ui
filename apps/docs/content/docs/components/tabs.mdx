## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@blips/ui/components/tabs"
```

```tsx
<Tabs defaultValue="account" className="w-[400px]">
  <TabsList>
    <TabsTrigger value="account">Conta</TabsTrigger>
    <TabsTrigger value="password">Senha</TabsTrigger>
  </TabsList>
  <TabsContent value="account">Faça alterações na sua conta aqui.</TabsContent>
  <TabsContent value="password">Altere sua senha aqui.</TabsContent>
</Tabs>
```

Sem `defaultValue`, a primeira aba (índice `0`) começa ativa. Por padrão a aba só é ativada com clique ou Enter/Espaço; passe `activateOnFocus` no `TabsList` para ativar ao navegar com as setas.

## Migrando da v2

- `TabsTrigger` agora é `Tabs.Tab` e `TabsContent` é `Tabs.Panel`. Os nomes exportados não mudaram.
- `onValueChange` recebe `(value, eventDetails)`, e o valor pode ser de qualquer tipo.
- `activationMode` saiu da raiz. No lugar entra `activateOnFocus` no `TabsList`, com padrão `false` (ativação manual). No Radix o padrão era automático.
- `forceMount` no `TabsContent` virou `keepMounted`.
- Atributos de estado: `data-state="active"` virou `data-active` na aba. Seletores como `data-[state=active]:` precisam virar `data-active:`.
- `asChild` no trigger virou `render`.
- Visual: `TabsList` passou de `h-9` para `h-8`, e o trigger e o conteúdo usam `text-xs`.

```tsx
// v2
<Tabs defaultValue="a" activationMode="automatic">
  <TabsList>
    <TabsTrigger value="a" className="data-[state=active]:font-bold">A</TabsTrigger>
  </TabsList>
  <TabsContent value="a" forceMount>…</TabsContent>
</Tabs>

// v3
<Tabs defaultValue="a">
  <TabsList activateOnFocus>
    <TabsTrigger value="a" className="data-active:font-bold">A</TabsTrigger>
  </TabsList>
  <TabsContent value="a" keepMounted>…</TabsContent>
</Tabs>
```
