## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Button } from "@blips/ui/components/button"
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@blips/ui/components/dialog"
```

```tsx
<Dialog>
  <DialogTrigger render={<Button variant="outline" />}>Abrir</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Você tem certeza absoluta?</DialogTitle>
      <DialogDescription>
        Esta ação não pode ser desfeita. Isso excluirá permanentemente sua conta
        e removerá seus dados dos nossos servidores.
      </DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose render={<Button variant="outline" />}>Cancelar</DialogClose>
      <Button>Confirmar</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

O `DialogTrigger` e o `DialogClose` renderizam um `<button>` próprio. Para usar um `Button` da lib, passe-o pela prop `render` em vez de colocá-lo como filho.

## Migrando da v2

A primitiva passou de Radix para [Base UI Dialog](https://base-ui.com/react/components/dialog).

- `asChild` saiu do `DialogTrigger` e do `DialogClose`. Use `render`.
- `onOpenChange` recebe `(open, eventDetails)`. Passar um `setState` direto continua funcionando.
- O `DialogContent` agora é o `Dialog.Popup`: saem `onEscapeKeyDown`, `onPointerDownOutside`, `onInteractOutside`, `onOpenAutoFocus`, `onCloseAutoFocus` e `forceMount`; entram `initialFocus` e `finalFocus`. O fechamento por Esc ou clique fora se controla no `Dialog` (root).
- Seletores `data-[state=open]` e `data-[state=closed]` viram `data-open` e `data-closed`.
- A largura padrão caiu de `sm:max-w-lg` para `sm:max-w-sm`. Quem dependia da largura antiga passa `className="sm:max-w-lg"`.

```tsx
// v2
<DialogTrigger asChild>
  <Button variant="outline">Abrir</Button>
</DialogTrigger>
<DialogClose asChild>
  <Button variant="outline">Cancelar</Button>
</DialogClose>

// v3
<DialogTrigger render={<Button variant="outline" />}>Abrir</DialogTrigger>
<DialogClose render={<Button variant="outline" />}>Cancelar</DialogClose>
```

## Referência da API

### DialogContent

| Prop              | Tipo      | Padrão |
| ----------------- | --------- | ------ |
| `showCloseButton` | `boolean` | `true` |

### DialogFooter

| Prop              | Tipo      | Padrão  |
| ----------------- | --------- | ------- |
| `showCloseButton` | `boolean` | `false` |

Para as demais props, consulte a documentação do [Base UI Dialog](https://base-ui.com/react/components/dialog).
