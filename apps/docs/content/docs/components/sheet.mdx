## Instalação

```bash
npm install @blips/ui
```

## Uso

```tsx
import { Button } from "@blips/ui/components/button"
import {
  Sheet,
  SheetBody,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetSection,
  SheetSectionTitle,
  SheetTitle,
  SheetTrigger,
} from "@blips/ui/components/sheet"
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Abrir</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Você tem certeza absoluta?</SheetTitle>
      <SheetDescription>Esta ação não pode ser desfeita.</SheetDescription>
    </SheetHeader>
    <SheetBody>{/* conteúdo */}</SheetBody>
    <SheetFooter>
      <SheetClose render={<Button variant="outline" />}>Fechar</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

O `SheetContent` não tem padding próprio: o `SheetHeader` e o `SheetFooter` já trazem o seu, e **todo conteúdo entre eles deve ficar dentro de um `SheetBody`** — é ele que dá o padding interno e o scroll. Não coloque conteúdo solto direto no `SheetContent`.

## Exemplos

### Lado

Use a prop `side` no `SheetContent` para definir a borda da tela onde o sheet aparece. Os valores são `top`, `right`, `bottom` ou `left`.

<ComponentPreview name="sheet-side" />

### Corpo rolável e seções

Use `SheetBody` para o corpo com scroll próprio (cabeçalho e rodapé ficam fixos) e `SheetSection` + `SheetSectionTitle` para agrupar o conteúdo em blocos separados por borda. Ao conter `SheetSection`, o `SheetBody` zera o próprio padding e cada seção controla o seu.

<ComponentPreview name="sheet-sections" />

### Sem botão de fechar

Use `showCloseButton={false}` no `SheetContent` para esconder o botão do canto superior direito.

## Anatomia

```tsx
<Sheet>
  <SheetTrigger />
  <SheetContent>
    <SheetHeader>
      <SheetTitle />
      <SheetDescription />
    </SheetHeader>
    <SheetBody>
      <SheetSection>
        <SheetSectionTitle />
        {/* conteúdo da seção */}
      </SheetSection>
    </SheetBody>
    <SheetFooter />
  </SheetContent>
</Sheet>
```

## Migrando da v2

A primitiva passou de Radix para o [Base UI Dialog](https://base-ui.com/react/components/dialog).

- `asChild` saiu do `SheetTrigger` e do `SheetClose`. Use `render`.
- `onOpenChange` recebe `(open, eventDetails)`.
- O `SheetContent` perde as props do Radix (`onEscapeKeyDown`, `onPointerDownOutside`, `onInteractOutside`, `onOpenAutoFocus`, `onCloseAutoFocus`, `forceMount`) e passa a aceitar as do `Dialog.Popup` (`initialFocus`, `finalFocus`). Fechar por Esc ou clique fora se controla no `Sheet` (root), com `eventDetails.reason` ou `disablePointerDismissal`.
- Seletores `data-[state=open|closed]` viram `data-open`/`data-closed`; a animação usa `data-starting-style`/`data-ending-style`. O `SheetContent` expõe `data-side`.
- O padding de `SheetHeader`, `SheetBody`, `SheetSection` e `SheetFooter` passou de `p-4` para `p-6`.

```tsx
// v2
<SheetTrigger asChild>
  <Button variant="outline">Abrir</Button>
</SheetTrigger>
<SheetClose asChild>
  <Button variant="outline">Cancelar</Button>
</SheetClose>

// v3
<SheetTrigger render={<Button variant="outline" />}>Abrir</SheetTrigger>
<SheetClose render={<Button variant="outline" />}>Cancelar</SheetClose>
```

## Referência da API

A maior parte das props vem do [Base UI Dialog](https://base-ui.com/react/components/dialog). Os componentes de layout abaixo são da `@blips/ui`.

### SheetContent

| Prop              | Tipo                                     | Padrão    |
| ----------------- | ---------------------------------------- | --------- |
| `side`            | `"top" \| "right" \| "bottom" \| "left"` | `"right"` |
| `showCloseButton` | `boolean`                                | `true`    |

### SheetBody

Corpo rolável entre o cabeçalho e o rodapé — `flex-1 overflow-auto p-6`. Quando contém `SheetSection`, remove o próprio padding (`has-data-[slot=sheet-section]:p-0`) e delega o espaçamento às seções.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### SheetSection

Bloco de conteúdo agrupado dentro do `SheetBody` — `border-t p-6`. Cada seção tem uma borda no topo, separando a primeira do cabeçalho e cada seção seguinte da anterior.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |

### SheetSectionTitle

Rótulo de uma `SheetSection` — `mb-4 text-xs font-medium text-muted-foreground`.

| Prop        | Tipo     | Padrão |
| ----------- | -------- | ------ |
| `className` | `string` | -      |
